# 🦈 小戴夫水下大冒險 (Dave the Diver: Kids Edition)
### 兒童專用 Google TV / Android TV 潛水捕魚與海洋探索遊戲

專為客廳大螢幕與電視遙控器設計的兒童水下探索遊戲，靈感源自《潛水員戴夫 (Dave the Diver)》與經典兒歌《Baby Shark》。

---

## 🌟 核心特色 (Key Features)

1. **真實細膩的人形潛水員戴夫 (Humanoid Scuba Dave)**：
   - 雙關節擺腿剪刀踢蛙鞋、雙氣瓶背包、潛水面鏡與呼吸調節器氣泡。
   - 動態水下頭燈光束（Headlamp Cone），隨升級擴展照明範圍。
   - 專為電視遙控器設計的物理滑行控制與 220ms 看門狗防暴衝煞車機制。

2. **四大深海地貌分層 (4 Depth Exploration Zones)**：
   - **0m - 75m（陽光珊瑚礁）**：光影波紋，小丑魚、藍倒吊、黃金蝶魚、海葵。
   - **75m - 200m（中層巨藻林）**：雙層隨洋流擺動之巨藻海帶林與金黃氣囊，巡遊著 Baby Shark 與黑鰭礁鯊。
   - **200m - 340m（沉船海溝）**：深藍海溝，巨型藍鰭鮪魚、大白鯊出沒。
   - **340m - 440m+（深淵發光洞穴）**：深邃幽暗的深淵黑夜，石壁長滿發光水晶鐘乳石，棲息著頭頂亮著燈籠擬餌的**深海安康魚 (Anglerfish)** 與**七彩霓虹水母**。

3. **海底沉船與探索互動 (Shipwreck & Treasures)**：
   - 海底 320m 處沉睡著一艘**傳奇海盜沉船殘骸**（古木龍骨、船長舵盤、桅杆瞭望台、大鐵錨與發光舷窗）。
   - **4 座互動式藏寶箱**：游近點亮金色光環，按下遙控器 `[OK]` 掀蓋噴發金幣光雨（+80 ~ +320 貝殼金幣）。
   - **巨型發光珍珠貝**：週期性呼吸開合，張開時可拾取稀世大珍珠（+90 金幣）。

4. **武器切換與友善海豚救援 (Bubble Gun & Dolphin Rescue)**：
   - **雙武器即時切換**：遙控器按 `[▲ 上鍵]` 隨時在「強力魚叉槍」與「氣泡催眠槍」之間切換。
   - **氣泡催眠槍**：發射七彩巨型泡泡包裹住攻擊中的鯊魚，使其立即進入安穩睡眠狀態（頭頂飄出 `💤 呼嚕呼嚕...`），靠近按 `[OK]` 即可**愛心活捉**獲得額外獎勵！
   - **友善海豚救援隊「波波」**：當氧氣偏低或耗盡時，粉藍海豚波波游來護航，按 `[OK]` 即載著戴夫以高速噴射氣泡安全送回水面，並獎勵 +50 金幣，絕不懲罰孩子。

5. **兒童視覺化裝備升級商店 (Kid-Friendly Visual Shop)**：
   - 告別繁瑣文字，採用大圖示向量卡片（氣瓶、蛙鞋、魚叉、頭燈）。
   - 8 級星級大師階梯進度條與挑戰解鎖機制（需捕獲指定目標以突破階級）。

6. **純淨兒歌背景音樂與生動音效 (Stereo Kids BGM & SFX)**：
   - 33 秒 44.1kHz 立體聲雙聲道熱帶海洋風配樂（Marimba 木琴、加勒比鋼鼓、跳躍低音與水下氣泡音）。
   - 完整音效庫：魚叉發射、捕獲成功、氣泡催眠、寶箱開啟、珍珠拾取、海豚鳴叫、升級祝賀、受傷音效。

## 🎮 電視遙控器操作指南 (TV Remote Controls)

| 按鍵 | 操作說明 |
| :--- | :--- |
| **方向鍵** `[▲ / ▼ / ◀ / ▶]` | 操控戴夫 360 度游動潛水 |
| **上鍵** `[▲]` | 靜止時快速切換武器：魚叉槍 ⇄ 氣泡催眠槍 |
| **確定鍵** `[OK / ENTER]` | 智能互動：發射武器／開寶箱／拾珍珠／活捉睡著魚／呼叫海豚救援 |
| **返回鍵** `[BACK]` | 游回水面柯布拉小船／進入升級商店 |

## 🛠️ 開發與編譯環境 (Build & Install)

- **目標平台**：Android TV / Google TV (API 21 - 34)
- **套件名稱**：`com.babyshark.tv`
- **架構支援**：arm64-v8a / armeabi-v7a

### 編譯 Debug APK
```bash
./gradlew assembleDebug
```

### 安裝至 Google TV
```bash
adb connect <TV_IP_ADDRESS>:5555
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
